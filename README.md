# Cat Novels Frontend

The frontend application for Cat Novels, a platform for publishing, discovering, and reading novels. Built with modern web technologies, it provides a user interface for browsing novels, reading content, and interacting with the platform.

## Features

- **Novel Discovery:** Browse and search for novels.
- **Novel Reading:** Read novels and their chapters through a web interface.
- **Content Editing:** Rich-text editing for novel content using TinyMCE.
- **User Authentication:** User login and authentication integration with the backend.
- **Multilingual Support:** Internationalization using i18next.
- **Content Sanitization:** HTML sanitization with DOMPurify.
- **Backend Integration:** Communicate with the Cat Novels Backend through REST APIs.

## Technologies

- JavaScript
- Vite
- HTML5
- CSS3
- TinyMCE
- DOMPurify
- i18next
- REST APIs

## Technical Highlights

- Developed a component-based frontend application.
- Integrated frontend functionality with backend REST APIs.
- Implemented rich-text content editing.
- Used DOMPurify to sanitize HTML content.
- Integrated internationalization with i18next.
- Separated frontend and backend responsibilities.

## Architecture

The project uses a frontend-backend architecture:

- **Frontend:** Vite-based web application responsible for the user interface and user interactions.
- **Backend:** Java Spring Boot service providing REST APIs, authentication, and application data management.
